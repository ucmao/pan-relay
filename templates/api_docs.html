Pan-Relay 开发者 API 接口指南

提供两步走中转逻辑：从资源检索 (包含纯站长收益库 `scope=own`) 到自动化转存替换专属链接 (`POST /api/v1/transfer`)，帮助第三方无缝集成并持续沉淀私有收益资产。

Base URL: /api/v1 Auth: X-API-Key

1. 两步走收益接入闭环

步骤 1 · 检索 GET /api/v1/search

查询资源信息

支持指定 scope=own 仅检索站长已有收益库（0 服务器开销、毫秒级响应、结果均为站长专属收益链），或 scope=all 全网聚合检索。

输入: 关键词 (keyword)
步骤 2 · 转存 POST /api/v1/transfer

替换为专属网盘收益链接

用户点击获取资源时，将原始链接提交给转存接口。后端自动把全网资源保存到站长云盘，生成站长专属分享链接，并自动沉淀为本地收益资产。

输入: 原始 url + 密钥

2. 接口安全鉴权 (`X-API-Key`)

为了保证网盘空间不被恶意刷爆，转存接口支持后台设置 API Key。当管理员配置了 Key 时，需要在 HTTP Header 中带上凭证：

鉴权方式 位置 传递格式与示例
X-API-Key 标头 (推荐) HTTP Header X-API-Key: <你的转存密钥>
Bearer Token 标头 HTTP Header Authorization: Bearer <你的转存密钥>
URL / Body 参数 Query / Body ?api_key=<你的转存密钥> 或 {"api_key": "xxx"}

* 注：若管理后台“转存 API 密钥”未设置（保持留空），转存接口默认为公开可调状态。*

3. API 核心节点规范

GET /api/v1/search
步骤 1 · 资源聚合搜索

根据关键词搜索库内或全网网盘资源。

参数 类型 必填 说明
keyword string 是 搜索关键词，例如：黑神话
scope string 否 own: 仅检索站长专属收益库; all: 全网聚合搜索。默认按后台配置。
cloud_name string 否 筛选网盘平台 (如：夸克网盘、百度网盘)
limit int 否 返回结果条数限制，默认 100
Response Example (JSON):
{
  "success": true,
  "scope": "own",
  "total": 1,
  "results": [
    {
      "title": "黑神话：悟空 高清合集",
      "share_link": "https://pan.quark.cn/s/my_relay_link_123",
      "cloud_name": "夸克网盘",
      "password": "",
      "source": "hot"
    }
  ]
}
POST /api/v1/transfer
步骤 2 · 替换为站长收益链接

将原始分享链接转存至站长云盘，生成站长专属收益链接。

Body 属性 类型 必填 说明
url string 是 待中转的原始网盘分享链接
title string 否 资源标题 (默认：未命名资源)
netdisk_name string 否 网盘名称 (如：夸克网盘、百度网盘)
Request Body (JSON):
{
  "url": "https://pan.quark.cn/s/raw_public_123",
  "title": "电影名称",
  "netdisk_name": "夸克网盘"
}
Response Example (JSON):
{
  "success": true,
  "message": "资源转换与链接生成成功",
  "data": {
    "url": "https://pan.quark.cn/s/my_relay_link_999",
    "mode": "temp_share",
    "netdisk_name": "夸克网盘"
  }
}
