Pan-Relay 开发者 API 指南

1. 两步走中转与收益沉淀闭环

第三方应用（如微信小程序、APP、Telegram 机器人等）接入本系统时，通过“搜索 -> 转存”两步完成外部资源的识别与专属收益转化：

步骤 1 · 检索 GET /api/v1/search

查询全网或站长收益资源

传参 scope=own 仅检索站长私有收益库（0 开销、毫秒响应、全是你的收益链）；传参 scope=all 进行全网检索。

步骤 2 · 转存沉淀 POST /api/v1/transfer

替换为站长收益分享链接

用户选中全网资源时，调用转存接口。后端自动保存文件至站长云盘，生成站长专属收益链接，并自动沉淀为站长个人私有资产。

原生免登录网盘链接测活保障 （覆盖 12 大网盘）

系统内置夸克、百度、阿里、UC、迅雷、123盘、天翼、115、移动云盘、联通云盘、悟空网盘、光鸭云盘的原生免登录探测引擎。步骤 1 搜索可开启 check_status=true 实时识别失效与空链接；步骤 2 转存默认执行前置测活校验（空资源、违规或失效链接直接返回 HTTP 422 拒绝转存），杜绝死链入库。

2. 接口鉴权机制 (`X-API-Key`)

为了避免恶意频繁调用消耗网盘容量，转存接口支持配置 API Key 鉴权：

鉴权方式 传递位置 语法示例 / 填写说明
X-API-Key HTTP Header 你的转存 API Key 凭证。X-API-Key: <YOUR_API_KEY> 推荐
Authorization HTTP Header 标准 Bearer 格式。Authorization: Bearer <YOUR_API_KEY>
api_key Query / Body URL 或 Body 传参。?api_key=<YOUR_API_KEY>

3. API 核心节点规范

GET /api/v1/status
基础概览 · 服务运行状态与 API 模式

检查后端服务连通性，并获取当前开启的服务模式（前台 UI、后台管理、默认检索作用域、转存 Key 配置状态及可用 API 端点列表）。无需鉴权。

GET /api/v1/search
步骤 1 · 聚合查询资源 (支持实时测活)
参数名 位置 类型 必选 说明
keyword Query String 必选 搜索关键词，例如：黑神话
scope Query String 可选 own: 仅站长收益库; all: 全网并发聚合（默认按系统配置）
cloud_name Query String 可选 指定网盘筛选，支持全称或常见简称/别名（如 百度、阿里、夸克、quark、115、123、uc 等），支持逗号分隔多个
limit Query Integer 可选 限制最大返回条数，默认 100
check_status Query Boolean 可选 是否对返回结果进行免登录实时测活，默认 false。开启后结果携带 health_state、health_summary、file_count。
filter_bad Query Boolean 可选 是否在服务端自动剔除已失效、违规封禁或内容为空的死链，默认 false。建议与 check_status=true 配合使用。
GET /api/v1/search/stream 强烈推荐 (UI首选)
步骤 1 (SSE) · 0等待秒级实时流式打字机推送

使用 Server-Sent Events (SSE) 协议实时流式返回搜索结果（包含 start / item / done 事件）。强烈推荐 Web 前端与小程序交互优先采用，支持客户端边检索边渲染，零卡顿提升用户体验。请求参数与 GET /api/v1/search 完全一致。

参数名 位置 类型 必选 说明
keyword Query String 必选 搜索关键词，例如：黑神话
cloud_name Query String 可选 指定筛选网盘（如 `百度`、`阿里`、`夸克`、`115` 等），支持逗号分隔或多值
limit Query Integer 可选 单次最大条数（受防护锁与后台预设控制）
scope Query String 可选 检索范围：own (站长收益库) 或 all (全网并发)
check_status Query Boolean 可选 是否实时并发测活并注入 health_state
filter_bad Query Boolean 可选 是否自动在服务端剔除已失效死链与空资源
POST /api/v1/transfer
步骤 2 · 自动转存替换 (前置测活防护)
Body 属性 类型 必选 说明
url String 必选 步骤 1 获取到的原始分享链接
title String 可选 资源名称标题（默认使用源标题或“未命名资源”）
netdisk_name String 可选 指定目标网盘名称（如：夸克网盘），留空则由系统智能推断
password String 可选 原始分享链接的提取码（若有）
skip_check Boolean 可选 是否跳过前置免登录测活检查，默认 false。保持 false 时，系统在转存前自动核验链接有效性与非空状态，异常时返回 HTTP 422 拦截。
前置测活校验拦截机制 HTTP 422 Unprocessable Entity

当未指定 skip_check=true 时，若源链接存在问题，接口将直接返回 422 状态码拒绝无意义转存，保护网盘转存配额：

code: "LINK_INVALID"
链接已失效、被封禁、下架或文件夹为空 (file_count = 0)
code: "LINK_LOCKED"
链接需要提取码，请在 Body 中补充 password 字段重新提交
POST /api/v1/link/check
实用工具 · 网盘链接免登录测活

原生探测 12 大网盘（夸克、百度、阿里、UC、迅雷、123盘、天翼、115、移动云盘、联通云盘、悟空网盘、光鸭云盘），免登录实时解析资源有效性、提取码状态、以及内部文件数量。支持单条与批量两种调用模式：

Body 属性 类型 必选 说明
url String 单条必选 待检测网盘分享链接
password String 可选 提取码（若链接有密码）
disk_type String 可选 指定网盘类型，留空自动根据 URL 正则识别
refresh Boolean 可选 是否强制跳过内存缓存实时请求，默认 false
items Array 批量必选 批量检测对象列表，例如：[{"url": "...", "password": ""}]
GET /api/v1/resources
资产管理 · 收益资源库列表
参数名 位置 类型 必选 说明
page Query Integer 可选 当前页码，默认 1
page_size Query Integer 可选 每页条数，默认 10
search Query String 可选 标题或链接关键字模糊筛选

4. 返回 JSON 数据字典

字段名 类型 含义与说明
success Boolean true 成功；false 失败。
scope String 搜索返回作用域：own (站长收益库) 或 all (全网)。
results Array 搜索结果列表，包含 title、share_link、cloud_name、source 以及开启测活时的健康字段。
health_state String 资源健康状态枚举： ok 正常有效 bad 失效/违规/空文件 locked 需提取码 uncertain 探测超时或未知
health_summary String 测活中文摘要，如“链接有效”、“分享链接无效：文件列表为空”。
file_count Integer 分享链接内包含的文件总数。若为 0 则判定为空资源下架。
code String 错误状态码标识：LINK_INVALID (链接失效/空资源 422)、LINK_LOCKED (缺少提取码 422)、INVALID_API_KEY (鉴权失败 401)。

5. 多语言对接代码示例 

# 步骤 1: 聚合搜索并过滤失效链接
curl -X GET "http://localhost:5004/api/v1/search?keyword=黑神话&check_status=true&filter_bad=true"

# 步骤 2: 发起转存替换 (默认前置测活校验，若链接失效/空文件夹则返回 422 拦截)
curl -X POST "http://localhost:5004/api/v1/transfer" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{"url": "https://pan.quark.cn/s/raw123", "title": "黑神话", "skip_check": false}'
