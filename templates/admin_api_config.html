REST v1 两步走中转与收益沉淀规范

Pan-Relay 开发者 API 指南

1. 两步走中转与收益沉淀闭环

第三方应用（如微信小程序、APP、Telegram 机器人等）接入本系统时，通过“搜索 -> 转存”两步完成外部资源的识别与专属收益转化：

步骤 1 · 检索 GET /api/v1/search

查询全网或站长收益资源

传参 scope=own 仅检索站长私有收益库（0 开销、毫秒响应、全是你的收益链）；传参 scope=all 进行全网检索。

步骤 2 · 转存沉淀 POST /api/v1/transfer

替换为站长收益分享链接

用户选中全网资源时，调用转存接口。后端自动保存文件至站长云盘，生成站长专属收益链接，并自动沉淀为站长个人私有资产。

2. 接口鉴权机制 (`X-API-Key`)

为了避免恶意频繁调用消耗网盘容量，转存接口支持配置 API Key 鉴权：

鉴权方式 传递位置 语法示例 / 填写说明
X-API-Key HTTP Header 你的转存 API Key 凭证。X-API-Key: <YOUR_API_KEY> 推荐
Authorization HTTP Header 标准 Bearer 格式。Authorization: Bearer <YOUR_API_KEY>
api_key Query / Body 兼容模式。?api_key=<YOUR_API_KEY>

3. API 核心节点规范

GET /api/v1/search
步骤 1 · 聚合查询资源
参数名 位置 类型 必选 说明
keyword Query String 必选 搜索关键词，例如：黑神话
scope Query String 可选 own: 仅站长收益库; all: 全网并发聚合
cloud_name Query String 可选 指定网盘筛选（夸克网盘、百度网盘、阿里云盘、UC网盘、迅雷网盘）
POST /api/v1/transfer
步骤 2 · 自动转存替换
Body 属性 类型 必选 说明
url String 必选 步骤 1 获取到的原始分享链接
title String 可选 资源名称标题

4. 返回 JSON 数据字典

字段名 类型 含义与说明
success Boolean true 成功；false 失败。
scope String 搜索返回作用域：own (站长收益库) 或 all (全网)。
results Array 搜索结果列表，包含 title、share_link、cloud_name、source。

5. 多语言对接代码示例 

curl -X POST "http://localhost:5004/api/v1/transfer" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_TRANSFER_API_KEY" \
  -d '{"url": "https://pan.quark.cn/s/raw123", "title": "黑神话"}'
