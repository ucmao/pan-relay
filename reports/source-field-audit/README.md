## 统一结果和字段适配

标准结果保留旧 `source` 字段，并增加 `source_type`、`source_id`、`source_name` 与 `metadata`。前端只显示来源类别：API、TG、插件或站长自建；具体 API/频道/插件标识继续保留在 SSE 与 REST 结果中。来源特有字段放入 `metadata`，序列化时递归剔除凭据类字段；标准密码仍单独输出。

API 用现有 JMESPath 规则选出标题和链接，再按键值把结果映射回完整原始记录；时间、简介、封面、密码会归一化，其余安全字段保留在 `metadata`。插件适配器补充保存 JSON 记录、搜索卡片字段以及详情页 Open Graph 信息。TG 解析结果保存频道标题、帖子链接、消息 ID 与浏览量。

## 验证边界

- 每个上游用有限关键词和页面采样；结果说明当前字段结构及适配路径，不代表覆盖该资源的所有历史记录和分页。
- 252035 盘搜早期成功样本含图片字段；后续连续遇到 403/超时，封面归一化由本地字段映射用例验证。
- 龙珠 API 的 TLS 证书过期。审计请求临时跳过证书验证仅用于确认字段，未更改生产请求的 TLS 行为；应更新上游证书后再做生产连通性确认。
- 插件空结果可能代表关键词无匹配；它与 HTTP 错误/超时在矩阵中区分。
